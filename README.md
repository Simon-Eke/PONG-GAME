# PONG - Project by Simon Eke

## Overview
This project aims to replicate the classic arcade game PONG using C# and Windows Forms. As a beginner to both game development and Windows Forms, I’ve focused on learning through building this game and using ChatGPT to help generate much of the code. The project is a work in progress, with plans to add new features and improvements over time.

## Current Features
- **Basic PONG gameplay**: Two paddles and a bouncing ball.
- **Player control**: A simple system where the player controls one paddle using keyboard inputs.

## Work in Progress
- **High Score**: Implementing a system to track and save high scores, either using SQL or a text file.
- **Bounce Mechanics**: Enhancing ball movement, including working with angles and improving bounce interactions.
- **Player vs CPU mode**: Developing a mode where the player competes against a computer-controlled opponent.

## Technologies Used
- **Programming Language**: C#
- **Framework**: Windows Forms

## Future Improvements
- Enhance AI for Player vs CPU mode
- Polish the user interface and add sound effects
- Additional difficulty levels and game settings
